# MettaOffice Pro

Software de escritorio de **Mettatec** para el procesamiento de datos geoespaciales: observaciones GNSS, rásters de elevación y ortofoto. Genera posiciones procesadas, informes y exportaciones.

> Este repositorio **solo distribuye los instaladores** de MettaOffice Pro. El software es propietario y requiere una licencia válida (ver [EULA](EULA.txt)).


## Requisitos del sistema

| Componente | Requisito |
| Sistema operativo | [Windows 10 / 11, 64 bits] |
| Procesador | Intel/AMD |
| Memoria RAM | [Minimo: 8 gb / Recomendado 16 gb] |
| Tarjeta de video | NVIDIA Gama RTX 2000 en adelante |
| Espacio en disco | 8 gb |

## Instalación

1. Descarga el instalador `.exe` desde Releases.
2. Ejecuta el instalador y acepta el acuerdo de licencia (EULA).
3. Sigue el asistente de instalación.
4. Abre MettaOffice Pro e ingrese su clave de activación.

> Si Windows SmartScreen muestra una advertencia al ejecutar el instalador, confirma que lo descargaste desde este repositorio antes de continuar.
